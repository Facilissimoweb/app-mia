# M. Teresa Rogani — Studio di design

Landing page responsive realizzata con React e Vite, ispirata al design system
e al prototipo forniti. Il modulo prepara una richiesta nella app di posta
predefinita dell'utente; il sito non raccoglie né conserva dati.

## Avvio in locale

```bash
npm install
npm run dev
```

Vite mostra nel terminale l'indirizzo locale da aprire nel browser.

## Produzione

```bash
npm run build
npm run preview
```
